# Fake GPS — лендинг

Готовый адаптивный сайт на HTML, CSS и JavaScript. Сборка и сервер не нужны.

## Как открыть
Откройте `index.html` в браузере. Для публикации загрузите все три файла (`index.html`, `style.css`, `script.js`) на статический хостинг, например GitHub Pages или Netlify.

## Уже работает
- адаптивное меню для телефона;
- плавное появление блоков при прокрутке;
- 3D-макет смартфона с анимацией и наклоном от движения мыши;
- демонстрационный выбор Одессы, Киева и Львова;
- кнопки «Новая точка» и приближения/отдаления демо-карты;
- FAQ-аккордеон;
- поддержка настройки `prefers-reduced-motion`.

## Важно
Демо на сайте — только визуальный макет. Оно не получает координаты пользователя, не подменяет системный GPS и не подключено к Google Maps. Ссылка на APK не добавлена, поскольку готового протестированного APK пока нет.
